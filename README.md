# SILES EMPIRE – zum Spielen

Hier liegt nur die spielbare Version von Siles Empire (früher Earth Empire) (aktuell V2.29).

**Online spielen:** https://silescrow.github.io/SilesEmpireGithub/

| Datei | Inhalt |
|---|---|
| `index.html` | Ladebildschirm und Hauptmenü |
| `game.js` | das Spiel (Steinzeit: Karte, Arbeiter, Ressourcen, Gebäude) |
| `models/` | 3D-Modelle der Steinzeit: Hütten, Zelt, Lager, Speicher, Kriegerhütten, Deko, Waffen, Tiere (Antilope, Hase, Wildpferd) |
| `weltkarte.png` | Umrisse der Kontinente für die Weltkarte |
| `audio.js` | Musik (Hauptthema, ruhige Spielmusik) und Geräusche, im Browser erzeugt |
| `musik_menue.mp3` | Menümusik „Crowns upon the Horizon“ |
| `musik_spiel.mp3` | Spielmusik „Before the Written Word“ |
| `three.min.js` | 3D-Bibliothek Three.js r160 |
| `laden.jpg`, `menue.jpg` | Ladebildschirm- und Menübild |
| `icon-*.png`, `manifest.webmanifest` | App-Symbol für den Startbildschirm |
| `version.txt` | aktuelle Version |

Alle Bilder, Texte und alten Versionen liegen in https://github.com/Silescrow/Siles-Empire
